
# Johann Strauss Sohn: Polka schnell „Vergnügungszug“ Op. 281 for piano two hands

This repository contains an MEI encoding of the Polka schnell *Vergnügungszug*,Op. 281 by Johann Strauss Sohn (Johann Strauss junior) for two-hands piano, following the [first edition by Spina, n.d. [1864],  Plate Plate C.S. 18.080](https://imslp.org/wiki/Special:ReverseLookup/261383).
